# Reproducible analysis environment for R (raer)

This is an _Apptainer_ container to ensure locked versions of operating system, R, and R packages.
It is based on the _Rocker_ project, and a date-stamped CRAN.

Check under _Releases_ to download the desired version.
Since GitHub does not allow files larger than 2GB, the image is split.
Follow install instructions on the _Release_ page.
